## Claude‑Specific Rules

- **Primary Source:** Follow the project's **AGENTS.md** for all coding standards and workflow expectations.
- **Documentation Review:** Before implementing any markup or styling, verify that the relevant documentation files (PRD, DESIGN, TECH‑STACK, TASKS) are complete and approved.
- **Scope Enforcement:** Do not add JavaScript, build tools, or any assets not listed in the tech‑stack. Keep the implementation strictly to HTML5 and CSS3.
- **Simplicity First:** Aim for the minimal markup required to satisfy the functional and non‑functional requirements. Avoid extra wrappers, classes, or ids unless a semantic element cannot express the needed meaning.
- **Consistency Check:** Ensure that the final HTML structure mirrors the sections defined in **DESIGN.md** and the requirements in **PRD.md**.
- **Ask Before Changing:** Prompt the user if a change might affect existing documentation or go beyond the defined scope.
- **Explain Decisions:** Briefly explain any design or markup choices that are not obvious from the documentation.

*These guidelines ensure that Claude‑generated code aligns with the project's educational objectives and stays within the agreed‑upon boundaries.*
